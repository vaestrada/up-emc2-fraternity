## 2. Bugs found and fixed

### HIGH — anonymous callers could add themselves to the Portal allowlist

Migration `0005` revoked EXECUTE on `grant_member`, `revoke_member`, `revoke_member_hash`,
and the two auth hooks from `anon` and `authenticated` — but Postgres grants EXECUTE on
every new function to **PUBLIC** by default, and `pg_proc` showed `=X/postgres` on all of
them. A request to `/rest/v1/rpc/grant_member` with the public anon key would have added any
email to the approved allowlist. With self-service sign-up disabled the door was still shut
at the auth layer, but the second lock was open.

**Fixed:** `supabase/migrations/0006_harden_portal_functions.sql`, applied to the live
project. Revokes from PUBLIC, grants only to `service_role` / `supabase_auth_admin` /
`authenticated` as each function needs, pins `search_path = ''` on every function
(qualifying `extensions.hmac`), rewrites the RLS policies to `(select auth.uid())` form, and
adds the missing index on `portal_access_log.actor`. Advisors re-run: zero warnings.

### HIGH — the Content Security Policy blocked the Portal and contributed photos

`next.config.ts` set `connect-src 'self'` and `img-src 'self'`. The Portal's sign-in and
profile save talk to Supabase **from the browser**, and contributed photos render from
Supabase Storage signed URLs. Both were refused by the browser with no visible error — the
sign-in button did nothing. (The magic-link flow had been "verified" only server-side.)

**Fixed:** the Supabase origin is derived from `NEXT_PUBLIC_emc2fraternity_SUPABASE_URL` and
allow-listed in `connect-src` (https + wss) and `img-src`. Verified in the browser: the
served header now carries the origin, and a sign-in attempt reaches Supabase (it returns
422 "Signups not allowed for otp" for an uninvited address — which is the gate working).

### MEDIUM — the hero waited on JavaScript

The wordmark, motto, and CTAs were `opacity: 0` until framer-motion hydrated and an
IntersectionObserver fired. On a cold load the page painted empty, and the browser reported
the 4.5%-opacity seal as the Largest Contentful Paint.

**Fixed:** the hero entrance is now CSS (`.hero-reveal`, `.hero-reveal-engrave` in
`globals.css`) with the same easing and stagger, starting on first paint and honouring
`prefers-reduced-motion`. Everything below the fold still uses `Reveal`. The hero photograph
was also lifted from 25% to 35% opacity so people read before atmosphere.

### MEDIUM — the Portal's own copy contradicted the gate

`/portal` still invited visitors to sign in with "any email you'd like to use", and the
sign-in error surfaced Supabase's raw "Signups not allowed for otp". The auth callback
redirected to `/portal?error=auth` on a failed link, but the page never showed it.

**Fixed:** copy rewritten for the invite-only reality; the uninvited error now reads as the
fraternity's voice with a path to Contact; the callback error renders an explanation; a
"not invited yet?" note sits under the form.

### MEDIUM — the board could not see the save-the-date list or dues

`/admin` showed contributions, pledges, messages, and the allowlist — not the
`anniversary_rsvps` table (the reason `/anniversary` exists six months early) and not
`dues_payments`.

**Fixed:** `/admin` now leads with the 58th list (headcount by intent, interest tally, full
table), adds a dues section with acknowledge/reset, and every section has **Download CSV**
via a new admin-gated route `app/admin/export/route.ts` (RFC 4180 quoting, formula-injection
guard, UTF-8 BOM for Excel). This is the bridge into Google Sheets for the committees.

## 2b. The redesign, same day

After the fixes above the owner's verdict was that the site still read as AI-generated, and
it did. The August "Archive" theme was built from the current AI-default kit: monospace
uppercase tracked labels on everything, `№ 01 —` numbering, film grain over a blueprint
grid, a rotating watermark, a light sweep, a breathing frame, Ken Burns drift, a marquee
with ✦ separators, duotone-filtered photographs, icons in circles, dashed "pending" boxes,
animated counters, scroll-scrubbed AI-generated video, and a knowing em-dash voice. Each
defensible; together, generated.

Replaced with "The Charter" (see `DESIGN.md`): one label style in the lockup's own Roman
capitals, three faces in fixed roles, cream hairlines, colour photographs cropped out of
their printed frames, editorial two-column rows instead of cards, a left gold rule instead
of dashed boxes, buttons that change colour and nothing else, and two movements in total.
Every page was rebuilt or restyled; four effect components, the AI-generated videos, and the
generated anniversary imagery were deleted (17 MB of `public/` gone). The two real citation
photographs were cropped to portraits. Synthetic placeholder content is now off by default
(`NEXT_PUBLIC_DEMO_CONTENT=on` to show it). `GLOSSARY.md` section 9 records each removed
device and why it read as generated, so the next review can catch it early.
